> Perfection of security interest in securities account
19.1. (1) Perfection of a security interest in a securities account also perfects a security interest in the security entitlements carried in the securities account.
> Perfection of security interest in futures account
(2) Perfection of a security interest in a futures account also perfects a security interest in the futures contracts carried in the futures account. SNWT 2009,c.14,s.107(15).
