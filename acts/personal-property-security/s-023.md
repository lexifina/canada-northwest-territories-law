> Continuity of perfection
23. (1) If a security interest is perfected under this Act and is again perfected in some other way under this Act without an intermediate period when it is unperfected, the security interest is continuously perfected for the purposes of this Act.
> Priority when security interest transferred
(2) A transferee of a security interest has the same priority with respect to perfection of the security interest as the transferor had at the time of the transfer.
